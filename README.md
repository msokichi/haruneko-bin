# haruneko-bin

Arch Linux (AUR) binary package for [HakuNeko](https://github.com/manga-download/haruneko).

This package repackages the upstream Electron client (distributed as a snap)
into an installable Arch package.

## Build

```sh
makepkg -si
```

## Install from AUR

```sh
yay -S haruneko-bin
```
